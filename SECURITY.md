# Reporting a vulnerability

Please report suspected security vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/admin9-labs/laravel-oidc-server/security/advisories/new).

Include the affected package and dependency versions, relevant configuration, reproduction steps, expected impact, and any proposed patch or regression tests. Remove credentials, private keys, and personal data from examples.

Please avoid disclosing vulnerability details in public issues or pull requests before a fix is available. We will coordinate review, remediation, and disclosure in the private advisory.
